Background research notes on Carnatic music theory, compiled during the literature review phase.

| File | Description |
|------|-------------|
| `Melakartas.md` | The 72 melakarta (parent scale) system — structure, numbering, and family relationships |
| `Ragas.md` | Raga definitions, arohana/avarohana, characteristic phrases (pakad), and janya-melakarta relationships |
| `Swaras.md` | The 12-swara system — note names, cent positions, and comparison to Western equal temperament |
